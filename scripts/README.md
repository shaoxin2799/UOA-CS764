# Acquisition utilities

- `download_atus.sh` — official BLS ATUS 2003–2024 six-file snapshot.
- `download_ts_seed.py` — THUML electricity/traffic/weather/exchange/ETT seed suite.
- `download_gifteval.py` — optional broader GIFT-Eval snapshot, with allow-pattern filtering.
- `build_manifest.py` — byte-size + SHA-256 manifest generator.
- `audit_aamas_inputs.py` — verifies required local raw inputs without attempting to bypass restricted sources.
- `preflight.py` — checks basic host tooling.
